## Where the real content lives today

**No formal, measured performance target exists anywhere in this
codebase today.** This is a real, current gap, not an oversight to paper
over — when this appendix is written, every target in it must be a real
measured number (e.g., "the 4,000-tick Reasoning Lab smoke test completed
in N seconds against SQLite on this hardware"), never an aspirational
round number invented for the document. Until real numbers are measured
and recorded, this appendix should stay a stub rather than publish
fabricated targets.
