Deprecated entries. This appendix should not duplicate `CHANGELOG.md` —

  organized under `## Unreleased` (all v0.7 work to date) and prior
  `## v0.6` / `## v0.5` / ... sections.
- `docs/VersionHistory.md` — the narrative, version-by-version summary.

When this appendix is written, it should add one thing neither existing
document has: a mapping from each changelog entry to the Design Bible
volume/chapter it belongs under.
