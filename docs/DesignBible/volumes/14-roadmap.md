## Note on version numbering

The game's shipped-feature version (tracked in `docs/VersionHistory.md`
and `CHANGELOG.md`) is currently v0.7. `docs/DEVELOPMENT_RULES.md` itself
carries a separate "v0.9" label as the governance-document version for
its own Elite Intelligence Objective, distinct from the shipped-feature
version. When this volume is written, it should reconcile these two
numbering schemes explicitly rather than leave readers to guess which
"version" a given "v0.9" reference means.
